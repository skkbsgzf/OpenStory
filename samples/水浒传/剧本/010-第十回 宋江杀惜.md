# 第一幕 夜客

*〔场景：郓城县，宋江寓所。夜。灯下一张书案。〕*

宋江正在抄公文。门被敲了三下，不轻不重。

**宋江**（抬头）：谁？

**刘唐**（门外）：宋押司，故人之后。

*〔宋江开门。刘唐闪身进来，把门带上。〕*

**宋江**（打量他）：你是谁？

**刘唐**（从怀里取出包裹，放在桌上，解开）：晁天王托我来的。

*〔一锭金子，一封书信。宋江看着那封信，没有立刻去拿。〕*

**宋江**（低声）：你是梁山上的人。

**刘唐**：是。

**宋江**（沉默）。他走到门口，听了一下外面的动静，然后回来，拆开信。

*〔他读得很慢。读到一半，脸色变了。〕*

**宋江**（把信折起来）：你走。

**刘唐**：押司，晁天王说——

**宋江**（打断）：我说你走。

*〔他把金子推回去。〕*

**宋江**：这些东西，我这里放不得。

**刘唐**：押司是嫌少？

**宋江**（看着他）：我救晁盖，是为了义。收了这金子，义就变卖。

*〔刘唐站着没动。〕*

**宋江**（把信塞进他手里）：信我留着，回书我写。

**刘唐**：那……

**宋江**：你今夜出城。

*〔刘唐把包裹收了，忽然说了一句。〕*

**刘唐**：押司，我们军师说，你是个少见的人。

**宋江**（笑了笑）：你们军师倒是会看人。

*〔刘唐走了。宋江把那封信重新展开，看了很久，然后把它折好，塞进衣箱最底层。〕*

# 第二幕 阎婆

*〔场景：郓城县，阎婆家楼下。午后。〕*

阎婆拦住宋江的去路，一把拉住他的袖子。

**阎婆**：押司！押司可算来了！

**宋江**（把手抽出来）：做什么？

**阎婆**：我那女儿，这几日茶饭不思，天天念着押司。

**宋江**：公事忙。

**阎婆**（不松手）：押司，你就上去坐一坐。坐一坐就走。

*〔她半拉半就。宋江被推着上了楼。〕*

*〔楼上。阎婆惜正在梳头。看见他，把梳子一放。〕*

**阎婆惜**（回头，笑）：押司来了。

**宋江**（站在门口）：我坐一坐就走。

**阎婆惜**：坐一坐。（起身，替他解外衣）押司脱了外衣，自在些。

*〔宋江站着没动。她替他把外衣脱了，挂在衣架上。〕*

# 第三幕 拾书

*〔场景：阎婆惜房内。夜。宋江睡下，背对着她。〕*

*〔灯还亮着。阎婆惜翻了个身，看见衣架上的外衣。〕

*〔她起身，走到衣架前，摸了摸衣箱。〕*

**阎婆惜**（低声）：这是什么。

*〔她打开衣箱。一封信，一锭金子。〕*

*〔她对着灯看信。看着看着，手抖起来。〕*

**阎婆惜**（低声）：梁山泊……

*〔床上的宋江动了动。〕*

**宋江**（翻身，睁开眼）：你在做什么？

**阎婆惜**（把信往身后一藏）：没……没什么。

**宋江**（坐起来，脸色变了）：给我。

**阎婆惜**：我凭什么给你？

**宋江**（下床）：那是我的东西。

**阎婆惜**（退到墙角，把信举起来）：宋江，你私通梁山贼寇。

*〔屋里静下来。〕*

**宋江**（站着，声音很低）：把它给我。

**阎婆惜**：给我三个条件。

**宋江**：你说。

**阎婆惜**：第一，任我从良。

**宋江**：好。

**阎婆惜**：第二，这屋里的家私，都归我。

**宋江**：好。

**阎婆惜**（笑了一下）：第三……

**宋江**：第三是什么？

**阎婆惜**（把信攥紧）：这封信，我留着。

# 第四幕 刀

*〔场景：阎婆惜房内。〕*

**宋江**（一动不动）：你留着这封信，是要我的命。

**阎婆惜**：我要的是我的活路。

**宋江**：我把家私都给你了。

**阎婆惜**：不够。（把信贴在胸口）有了这封信，我这一辈子都有人怕我。

**宋江**（往前走了一步）：那我一辈子都得怕你。

**阎婆惜**（后退，声音尖了）：你别过来！你再走一步我就喊！

*〔宋江没停。〕*

**阎婆惜**（张嘴）：来——

*〔宋江伸手去夺。她死死攥住不放。〕*

*〔两个人扭在一起。桌子翻了，灯灭了。〕*

*〔黑。〕*

*〔然后是一声很轻的、很短的声音。〕*

*〔然后什么都没有了。〕*

*〔月光从窗缝里照进来。宋江跪在地上，手里有一把刀。阎婆惜躺在他面前。〕*

**宋江**（很久，才说出话）：我……不是要杀你。

*〔他把那封信从她手里抽出来，塞进怀里。〕*

**宋江**（站起来）：我是要那封信。

# 第五幕 逃走

*〔场景：阎婆惜房内。宋江把外衣穿上，正要下楼。〕*

*〔楼下，阎婆的声音。〕*

**阎婆**（在楼下）：押司？押司要走了？

*〔宋江站在楼梯口，没动。〕*

**阎婆**（上楼）：押司，这么晚了……

*〔她走到楼梯一半，看见屋里的情形。〕*

**阎婆**（一声尖叫）：啊——！

**宋江**（退到窗边）：妈妈。

**阎婆**（扑到女儿身上，回头看他）：你……你杀了她！

**宋江**：她拿了我一件东西。

**阎婆**（哭喊）：杀人啦！宋江杀人啦！

*〔宋江推开窗，跳了下去。〕*

# 第六幕 都头

*〔场景：郓城县，后门小巷。夜。〕*

*〔朱仝在巷口等他。〕*

**朱仝**（低声）：押司，这边。

**宋江**（过去，喘）：朱都头……

**朱仝**：别说话，跟我走。

*〔两人穿过两条巷子。雷横在城墙根下等着，把一包东西递过来。〕*

**雷横**：盘缠。城门的钥匙我拿了。

**宋江**（看着他们俩）：你们……

**朱仝**（打断）：押司，你平日待我们怎么样，我们都记着。

**雷横**：快走。

**宋江**（抱拳，很深）：二位恩义，宋江记下。

**朱仝**：记不记下不打紧。

*〔他把宋江往城墙上推。〕*

**朱仝**：活着。

*〔宋江攀上城墙。他回头看了一眼这座城。〕*

**宋江**（低声）：我这一走……

**雷横**：押司！

*〔宋江跳了下去。〕*

# 第七幕 沧州

*〔场景：郓城县城外，小路。月光。〕*

*〔宋江一个人走。他从怀里摸出那封信，看了一眼，然后撕开，撕成碎片，撒在风里。〕*

**宋江**（看着碎片飞走）：晁天王，这一封书，我宋江还了。

*〔他往前走。前面是去沧州的路。〕*

**宋江**（自语）：柴大官人的庄子……我从前去过一次。

*〔他忽然笑了一下，笑声在夜里很轻。〕*

**宋江**：那时候我还是个押司。如今我是个杀人的逃犯。

*〔他继续走。〕*

**宋江**：可我救的那个人，如今是梁山寨主了。

*〔他的背影消失在月色里。〕*

*〔正是：押司私放天王，怒杀婆惜走他乡。〕*

*〔毕竟宋江到柴进庄上如何，且听下回分解。〕*
