# 第一幕 教头的病

*〔场景：东京，禁军教头宅。秋雨。檐水一线一线落进庭院。〕*

王进坐在廊下，手按着膝盖，脸色蜡黄。院中校场上，几个军汉在雨里练棒，喊声隔着一层雨传过来，闷闷的。

**王母**（端药出来）：又坐在这里吹风。喝了。

**王进**（接过碗，没喝）：母亲，我听说殿帅府换了人。

**王母**：换了谁？

**王进**（沉默一下）：高俅。

**王母**（愣住）：哪个高俅？

**王进**：就是……父亲当年在街上打过的那个泼皮高二。

*〔碗里的药晃了一下。〕*

**王母**：你父亲打他，是他该打。

**王进**：我知道。可他如今是殿帅府太尉。

# 第二幕 点卯

*〔场景：殿帅府，点卯厅。晨。满厅将校按班站立。〕*

高俅坐在上首，一身紫袍，手里转着一枚玉扳指。他一个一个看下去，看到末位时停住。

**高俅**：王进。

**王进**（出班）：在。

**高俅**（慢慢道）：我听说，你病了半个月？

**王进**：是。旧疾未愈。

**高俅**：旧疾。（笑了一下）你父亲当年也有旧疾——手上有旧疾，专好打人。

*〔满厅无人出声。有人低下头。〕*

**高俅**：今日起，你每日卯时到府，我亲自看你点卯。迟一刻，军法治。

**王进**（垂眼）：……是。

*〔散班时，同僚从他身边走过，谁也没看他。〕*

# 第三幕 夜走

*〔场景：教头宅，夜。一盏灯。〕*

王进把行李捆了又拆，拆了又捆。母亲坐在灯下，看着他。

**王母**：你要走。

**王进**（手停下）：母亲，高俅不会只让我点卯。

**王母**：我知道。

**王进**：他会找一个由头。今日点卯，明日校场，后日就能军法。

**王母**：那你带上我。

*〔王进跪下。〕*

**王进**：带不了。两个人出城，官面上的人一问就露。

**王母**（扶他起来，声音很平）：你是要我先死在这里？

**王进**：母亲！

**王母**：我留在这宅子里，高俅反倒不好动我——满城都知道你走了，我若有个三长两短，天下人都看着他。

*〔王进不说话。灯芯爆了一下。〕*

**王进**：延安府有个老种经略相公，父亲旧部。我投他去。

**王母**：去。

**王进**（磕头，额头抵在砖上）：母亲保重。

*〔四更。城门口开了一线。王进牵马出城，头也不回。〕*

# 第四幕 史家村

*〔场景：史家村，打麦场。午后。晒着新麦。〕*

史进在场上使棒，一身刺青在日光下发亮。二十来个村汉围看，没人敢上。

**史进**（收棒，喘）：还有谁？

*〔人群里有人笑了一声。史进看过去。〕*

**史进**：你笑什么？

**王进**（站在场边，挑着担子）：我笑你使得好看。

**史进**：好看？

**王进**：好看，不能打。

*〔场上一静。史进脸上变了。〕*

**史进**（把棒一横）：你下来。

**王进**（放下担子）：我先教你一句话——棒不是抡的。

*〔他走过去，随手从旁边抽了一根木杆。〕*

**史进**：你就用这个？

**王进**：来。

*〔史进扑上。只一个照面，他手里的棒飞了出去，落在麦堆上。〕*

*〔全场无声。史进站在原地，半晌，忽然跪了下去。〕*

**史进**：教头！

**王进**（扶他）：我不是教头了。

**史进**：你就是。我史进拜你为师！

# 第五幕 少华山

*〔场景：史家村，庄上厅堂。夜。灯下摆着酒。〕*

**史进**（举杯）：师父，这三位是少华山的头领。朱武、陈达、杨春。

**朱武**（起身，拱手）：史大郎的师父，就是我等的长辈。

**王进**（看他一眼）：你们落草？

**朱武**：逼不得已。县里加了三回税。

**王进**：落草也是路。只是莫害百姓。

**朱武**：不敢。

*〔门外忽然一声梆子。〕*

**庄客**（冲进来，喘）：大郎！李吉去县里告了——说庄上藏了山贼！官兵围了庄子！

*〔史进一按桌面，酒碗跳起来。〕*

**史进**：李吉？那个打猎的？

**庄客**：就是他。

**史进**（咬牙）：我待他不薄。

**王进**：现在说这个没用。几路兵？

**庄客**：前后都堵了。三百多。

**史进**（回头）：师父，你先走。

**王进**（摇头）：我走不了。

**史进**：你是客人！

**王进**：我是你师父。

*〔两人对视。〕*

**史进**（忽然笑了）：好。那就一起走。

# 第六幕 烧庄

*〔场景：史家村，火光冲天。〕*

**史进**（举火把）：庄子留不得了。

**朱武**：庄上这些年的家业——

**史进**：家业烧了还能挣，人留下才叫家业。

*〔他把火把扔上屋檐。火一下窜起来。〕*

*〔四人杀开一条路，冲进夜色里。〕*

*〔史进回头。火光照着他的脸，他什么也没说。〕*

*〔次日，少华山下。王进把担子放下。〕*

**王进**：我就送到这里。

**史进**（急）：师父，你也上山。

**王进**（摇头）：我还有母亲在东京。

**史进**：我派人去接！

**王进**：不用。（顿了顿）你若真想报我这个师恩，就记住一句话。

**史进**：师父说。

**王进**：别学高俅。

*〔他挑起担子，往延安府去。史进站在山口，一直看到那个背影消失。〕*

*〔正是：教头避祸走延安，少年烧庄上华山。〕*

*〔毕竟王进到延安如何，且听下回分解。〕*
