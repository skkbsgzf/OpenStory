# 第一幕 菜园

*〔场景：东京大相国寺，菜园。晨。菜畦整齐，四围一道矮土墙。〕*

智清禅师把一串钥匙递给鲁智深。

**智清禅师**：管菜园。菜不许少，也不许人进来。

**鲁智深**（掂着钥匙）：管菜园？

**智清禅师**：先管好菜园，再说别的。

*〔墙外。二三十个泼皮挤在墙根，探头探脑。〕*

**泼皮甲**（低声）：新来的和尚，听说打死了人。

**泼皮乙**：管他打死谁，进了这园子，就得听咱们的。

**泼皮甲**：老规矩，哄到粪坑边，一推了事。

# 第二幕 反制

*〔场景：菜园。粪坑边。〕*

泼皮们提着两坛酒、一只熟鸡进来，笑得满脸殷勤。

**泼皮甲**：师父新来，咱们备了些酒菜。

**鲁智深**（看着他们，笑）：好。放那儿。

**泼皮甲**（往坑边引）：师父这边坐，这边凉快。

**鲁智深**：凉快？

*〔他走了两步，忽然一伸手，抓住泼皮甲的腰带。〕*

**泼皮甲**（惊）：师父做什么？

**鲁智深**：你不是说那边凉快么。

*〔一送。泼皮甲进了粪坑。〕*

**泼皮乙**（转身要跑）：快跑！

**鲁智深**（追上，一脚）：你也凉快凉快。

*〔第二个也下去了。〕*

*〔剩下的人全跪了。〕*

**众泼皮**：师父饶命！我们有眼不识泰山！

**鲁智深**（拍拍手）：起来。日后这园子的菜，我许你们吃，但不许偷。

**众泼皮**：是！是！

**泼皮甲**（在坑里）：师父……拉我一把。

**鲁智深**（回头）：自己爬。

# 第三幕 拔树

*〔场景：菜园，绿杨树下。午后。众泼皮买了酒肉，围坐。〕*

酒吃到一半，树上乌鸦叫起来，一声接一声。

**泼皮乙**：这扁毛畜生，天天叫。我搬梯子拆了它的巢。

**鲁智深**（放下酒碗）：拆什么巢。

**泼皮乙**：不拆它叫。

**鲁智深**（站起来，走到树下，仰头看了一眼）：看我的。

*〔他脱了直裰，露出一身刺青。右手向下，左手向上，抱住树干。〕*

**众泼皮**（笑）：师父这是要摇树？

*〔鲁智深腰只一趁。〕*

*〔绿杨树带根而起。泥土从根上簌簌落下。〕*

*〔众泼皮的笑僵在脸上。园子里静了一瞬，然后全都拜了下去。〕*

**众泼皮**：师父真罗汉！

**鲁智深**（把树一放，掸手）：酒呢。

# 第四幕 墙外

*〔场景：菜园，矮墙边。〕*

鲁智深在园中使禅杖。杖风扫过，菜叶纷飞。众泼皮围在四周叫好。

*〔墙缺处，一个官人站着看了半日。〕*

**林冲**（自语）：好个花和尚。

*〔鲁智深收了杖，看见他。〕*

**鲁智深**：墙外那位，看了这半日，怎么不说话？

**林冲**（越过墙缺进来，抱拳）：八十万禁军教头，林冲。

**鲁智深**（上下看他）：教头？

**林冲**：方才这一路杖，我认得——五台山的路子。

**鲁智深**（笑）：你倒识货。

**林冲**：我请你吃酒。

**鲁智深**：这酒我吃。

*〔两人坐到树下。众泼皮添了碗。〕*

**林冲**：师兄为何到这园子里来？

**鲁智深**：说来话长。我打死过人。

**林冲**（不动声色）：打死的，该打么？

**鲁智深**（看他）：该打。

**林冲**（举碗）：那便吃。

*〔碗刚碰上，墙外一阵急喊。〕*

# 第五幕 东岳庙

*〔场景：菜园。锦儿从园门外扑进来。〕*

**锦儿**（喘，声音都变调）：官人！官人！娘子在东岳庙里，被……被人拦住了！

*〔林冲手里的碗落在菜畦里。〕*

**林冲**（起身）：什么人？

**锦儿**：不知道，一个后生，围着娘子不放，还说要带她走！

*〔林冲转身就走。走了两步，回头。〕*

**林冲**：师兄，借你的园子放一放。

**鲁智深**（抄起禅杖）：我同你去。

*〔东岳庙。廊下。〕*

*〔张氏被逼在廊柱边，一个锦衣少年拦在面前，几个帮闲围着。〕*

**高衙内**（笑）：娘子，随我回去，有你的好处。

**张氏**（后退）：你让开！

**林冲**（冲进来，一把扳过他的肩）：放手！

*〔少年转过身。林冲的手停在他肩上。〕*

**林冲**（声音低下去）：……衙内。

**高衙内**（看清他，反倒笑了）：哟，林教头。这是你娘子？

**林冲**（手还搭在他肩上，没松开，也没握紧）：衙内，请自重。

**高衙内**（把他的手拨开）：自重？（笑）林教头，你教我自重？

*〔廊外，鲁智深提着禅杖赶到。〕*

**鲁智深**（看见那少年，杖尖一抬）：教头让开，待我打这厮！

**林冲**（横身拦住）：师兄住手！

**鲁智深**（顿住）：教头？

**林冲**（低声，很快）：他父亲是高俅。

*〔鲁智深愣住。禅杖在半空停了一瞬。〕*

**鲁智深**：那更该打。

**林冲**（抓住他的胳膊，力气很大）：师兄。我一家老小。

*〔鲁智深看着他。半晌，把杖放下。〕*

**鲁智深**（冷冷地看高衙内）：你走吧。

**高衙内**（整整衣襟，笑着，走得慢）：林教头，改日府里见。

*〔他走了。廊下只剩下林冲、张氏、锦儿，和提着禅杖的鲁智深。〕*

**张氏**（哭）：官人……

**林冲**（没有回头看她，只看着高衙内走的方向）：回家。

*〔鲁智深站在廊下，看着他的背影。〕*

*〔正是：花和尚倒拔垂杨柳，豹子头忍辱避衙内。〕*

*〔毕竟林冲如何，且听下回分解。〕*
