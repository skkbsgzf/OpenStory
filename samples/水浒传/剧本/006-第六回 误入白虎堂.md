# 第一幕 宝刀

*〔场景：东京，街市，刀铺前。午后。铺子里挂着十几口刀，都不出鞘。〕*

林冲在铺子前来回走了三趟。第四趟，他站住。

**林冲**：这口刀，拿来看看。

**刀客**（把刀捧出来）：好眼力。这刀，三千贯。

**林冲**（抽刀半寸，光在刃上走了一线）：三千贯？

**刀客**：少一文不卖。

**林冲**（看那刀，看了很久）：我买了。

*〔他把刀插进鞘里，一路把玩回去。走到教头宅门口，还在看。〕*

**张氏**（在门内）：官人回来了？

**林冲**（把刀递给她看）：你看这刀。

**张氏**（看了一会儿）：好是好。家里哪来这些钱？

**林冲**（笑）：我把马卖了。

*〔张氏没说话。〕*

# 第二幕 传唤

*〔场景：教头宅，次日晨。门口。〕*

陆谦站在门外，一身新衣，笑得客气。

**陆谦**：林教头，太尉请你过府。

**林冲**（一凝）：太尉？什么事？

**陆谦**：不晓得。只说太尉听说教头得了口好刀，要看看。

**林冲**（手按在刀上）：太尉怎么知道我得了刀？

**陆谦**（笑）：东京城这点事，太尉能不知道？

*〔林冲站着不动。〕*

**陆谦**：教头？

**林冲**：走。

# 第三幕 白虎堂

*〔场景：太尉府，府内长廊。午。长廊极长，两边无人。〕*

陆谦引路，越走越深。林冲握着刀，跟在他身后半步。

**林冲**（低声）：这是往哪去？

**陆谦**：太尉在白虎堂。

**林冲**（脚步一顿）：白虎堂？

**陆谦**（不回头）：教头，太尉等着呢。

*〔门开着。陆谦一侧身。〕*

**陆谦**：教头请。

*〔林冲进去。门在他身后合上。〕*

*〔堂内空无一人。四壁挂着甲胄与军图。正中一块匾：白虎节堂。〕*

**林冲**（环顾，忽然明白）：陆谦——

*〔堂后屏风一转。高俅出来，身后跟着十几个甲士。〕*

**高俅**（指着他手里的刀）：林冲。你带刀擅入白虎节堂，欲刺本官？

**林冲**（把刀往下一垂）：太尉！是陆谦唤我来——

**高俅**（打断）：陆谦？（回头看）我府里有这个人么？

**甲士**（齐声）：无。

*〔林冲回头。门还合着。陆谦不在。〕*

**林冲**（声音沉下去）：太尉。是我错了。

**高俅**：错了？

**林冲**：我不该信他。

**高俅**（走近，声音很轻）：林冲，你错在别处。

*〔他伸手，把林冲手里的刀抽出来。〕*

**高俅**：你错在，你娘子生得好。

*〔刀被丢在地上。甲士扑上。枷锁扣住林冲的颈。〕*

# 第四幕 休书

*〔场景：开封府狱，廊下。三日后。〕*

张氏与锦儿在栅外。林冲戴着枷坐在里面。

**张氏**（手伸进栅缝）：官人！

**林冲**（没有伸手）：别哭。

**张氏**：我去求太尉……

**林冲**（抬头，声音硬）：不许去。

**张氏**：官人……

**林冲**：你听我说。（顿了顿）我发配沧州。这一去，生死不知。

**张氏**：我等你。

**林冲**：不许等。

*〔他从怀里摸出一张纸，隔着栅递出去。〕*

**林冲**：休书。你拿着。

**张氏**（不接）：我不接。

**林冲**：你接了，高衙内就没了由头。

**张氏**（哭了）：那我没了你。

*〔林冲把休书塞进她手里，攥了一下。〕*

**林冲**：活着，比什么都强。

*〔他转过身，把背对着栅门。〕*

# 第五幕 野猪林

*〔场景：沧州路上，野猪林。午后。林深，日光碎成一片一片。〕*

董超、薛霸押着林冲走进林子。

**董超**：教头，走不动了。这林子僻静，歇了罢。

**林冲**（喘）：歇。

*〔他把枷靠在树上，坐下。薛霸在一旁烧水。〕*

**薛霸**（低声，对董超）：上头要结果他，你我动手。

**董超**（也低声）：路上动手，怕人看见。

**薛霸**：这林子前后三十里没人家。

*〔林冲闭着眼。他没有睡着。〕*

**薛霸**（端着水过来，笑）：教头，喝口水。

**林冲**（睁眼，看他）：薛霸。

**薛霸**：嗯？

**林冲**：这水里有东西吧。

*〔薛霸的手一抖。〕*

**薛霸**（把碗一摔，从腰里抽刀）：教头，对不住了。

*〔刀举起来。〕*

*〔松树后一声断喝。〕*

**鲁智深**（禅杖扫出）：好狗才！

*〔禅杖挑在薛霸手腕上。刀飞出去，插在土里。〕*

**董超**（跪）：好汉饶命！

**鲁智深**（把禅杖压在薛霸肩上）：说。谁叫你们动手？

**薛霸**（发抖）：是……是陆虞候。给了我们十两金子。

*〔鲁智深的手紧了一下。〕*

**林冲**（开口）：师兄。

**鲁智深**（回头）：嗯？

**林冲**：留他们性命。

**鲁智深**：留？

**林冲**：留他们回去回话。让他们告诉陆谦——林冲没死。

*〔鲁智深看着他，半晌，把杖收了。〕*

**鲁智深**：好。（对两个公人）滚。

# 第六幕 道别

*〔场景：沧州界，官道。黄昏。〕*

走了十几日，到了沧州界。路牌立在道边。

**鲁智深**（把行李放下）：兄弟，我就送到这里。

**林冲**：师兄再送一程。

**鲁智深**（摇头）：再往前，就进了沧州牢城的地界。我一个和尚，跟着你走，反倒给你添事。

*〔林冲不说话。〕*

**鲁智深**：兄弟。

**林冲**：嗯。

**鲁智深**：你太会忍了。

*〔林冲抬头。〕*

**鲁智深**：在东京，你忍；在这路上，你还忍。忍到最后，忍出什么来了？

**林冲**（沉默很久）：忍出我娘子还在东京。

*〔鲁智深愣住。然后他伸手，拍了拍林冲的肩。〕*

**鲁智深**：那你接着忍。

*〔他挑起行李，转身走了几步，回头。〕*

**鲁智深**：要是有事，俺必来。

**林冲**：师兄。

**鲁智深**：嗯？

**林冲**：替我……看着点东京。

*〔鲁智深没答话。他走了。〕*

*〔林冲披枷前行。走了很远，回头看了一眼，道旁已经没有人。〕*

*〔正是：教头误入白虎堂，刺配沧州路茫茫。〕*

*〔毕竟林冲在草料场如何，且听下回分解。〕*
