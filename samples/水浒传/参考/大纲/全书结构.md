# 水浒传全书结构

## 三大部分

### 一、聚义（第 1–71 回）

从洪太尉误走妖魔起，到一百单八将排座次止。

核心动因：**一个个好人被逼上梁山**。

- 第 1 回：误走妖魔（楔子）→ 见 [[宋江]] 之外的总纲
- 第 3–8 回：鲁智深、林冲的遭遇 → [[鲁智深]]、[[林冲]]
- 第 12–20 回：智取生辰纲 → [[智取生辰纲]]
- 第 23–32 回：武松的故事 → [[武松]]
- 第 36–41 回：宋江的流亡与浔阳楼 → [[浔阳楼]]
- 第 44–71 回：四方好汉陆续上山，终至排座次

### 二、招安（第 72–82 回）

排座次后，宋江力主招安。见 [[招安之争]]。

两破童贯、三败高俅，反而更坚定了宋江要「正名」的心。

### 三、征伐与凋零（第 83–120 回）

- 招安后征辽、征田虎王庆、征方腊
- 征方腊是全书最惨烈的一段：十损七八
- 结局：宋江、李逵被毒死，吴用花荣自缢于蓼儿洼

## 结构特点

| | 前半（聚义） | 后半（招安） |
|---|---|---|
| 叙事 | 一个人一个人地写（列传体） | 一支军一支军地打（战争体） |
| 情绪 | 酣畅 | 压抑 |
| 主角 | 各好汉轮流 | 宋江一人 |

> 写作提示：续写时先判断你要写的是「哪一部分」。聚义段可以写个人传奇，招安段必须有全局悲剧感。
