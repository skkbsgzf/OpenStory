# 古代官爵制度速查

写作工具书。只列写作高频项，考据以正史职官志通识口径为准；架空世界可据此变形。

## 一、九品十八级（六品以上写作高频区）

| 品级 | 正/从 | 朝代典型官职（唐—明清通识） | 写作身份感 |
|---|---|---|---|
| 正一品 | 正 | 三师三公（太师/太傅/太保）、殿阁大学士（明清） | 位极人臣，通常不掌实权，多用于「加衔尊崇」 |
| 从一品 | 从 | 少师少傅少保、将军（唐） | 顶级荣衔 |
| 正二品 | 正 | 尚书（唐宋）、六部尚书加衔（清） | 实权宰执级 |
| 从二品 | 从 | 布政使（明清）、光禄大夫 | 封疆大吏 |
| 正三品 | 正 | 六部尚书（明初定制前）、大理寺卿、通政使 | 京卿 |
| 从三品 | 从 | 光禄寺卿、盐运使 | 肥缺闻名 |
| 正四品 | 正 | 大理寺少卿、太常寺卿、府尹（顺天府/应天府） | 京官中坚 |
| 正五品 | 正 | 郎中（六部各司主官）、同知 | 部院司官之长，剧情里「实干事的人」 |
| 从五品 | 从 | 员外郎（唐宋为清贵，明清为副手）、知州 | |
| 正六品 | 正 | 主事、通判 | 进士起步常授 |
| 正七品 | 正 | 知县（明清）、翰林院编修 | 「芝麻官」原型；明清知县正七品是写作最常用锚点 |
| 从七品 | 从 | 州判、翰林院检讨 | |

写作要点：明清「七品知县」是身份锚点；唐宋品级与职事官分离（官、职、差遣三途），写唐宋背景不要拿明清品级套。

## 二、爵位（先秦五等爵 → 历代沿用为虚衔）

公、侯、伯、子、男五等。写作要点：汉代封侯（列侯）是真实富贵有封邑；唐以后爵位渐成荣衔；明清「国公」多为功臣世袭尊号（如英国公、魏国公），不等于实权。架空创作常用「一字王/二字王」区分亲疏（一字并肩王是戏说，正史无定制，可用但须知是创作惯例）。

## 三、称谓速查（写作高频错区）

- **对官**：大人（明清口语可用，唐宋正式场合称官职：「张尚书」「李刺史」）；明府（知县）、观察（唐代对观察使）、制台/抚台/藩台/臬台（清代总督/巡抚/布政使/按察使的尊称系统）。
- **对己**：下官（对上级）、微臣（对皇帝）、老夫（老年官员自谦）、本官（公堂自称，明清剧常用，正史口语色彩）。
- **官家/主上/陛下/圣上**：官家是宋特色；圣上/陛下通用。
- **官员之妻**：诰命夫人按夫品级（一二品夫人/夫人/淑人/恭人/宜人/安人/孺人，自一二品至七品），「一品诰命」是写作高频卡点，别写「三品诰命夫人」，三品对应「淑人」。
- **顶戴品色（清）**：一二品红宝石顶，三品蓝宝石，四品青金石，五品水晶，六品砗磲，七品素金。写清代背景「六品顶戴」应是白底砗磲顶，不是金顶。
- **补子（清）**：文官飞禽（一品仙鹤、二品锦鸡、三品孔雀、七品鸂鶒）、武官走兽（一品麒麟、二品狮子）。常见错误：把武官写成飞禽。

## 四、常见考据错误清单

1. 「正一品丞相」——明清无丞相（洪武废相），写明清背景用内阁大学士/军机大臣。
2. 「xx尚书令」当小官——尚书令在唐是宰相级，太宗曾任后虚置；写「尚书令」要么唐前要么慎重。
3. 「知府是四品」——清初知府正四品，乾隆后从四品；架空无妨，写实要留意。
4. 「伯爵比子爵大所以更有权」——唐宋以后爵位与实权脱钩，权在差遣不在爵。
5. 把「刺史/太守/知州/知府」混用同一朝代——汉魏晋刺史、唐刺史州、宋知州、明清知府，各随朝代。
