# 宫斗网文创作手册·礼仪与位分秩序

写给宫斗/宅斗作者的参考手册。原则：**礼仪位分是权力秩序的外显语言**——写礼不是背礼，是写谁在什么时候必须向谁低头。

## 一、位分阶梯（以清宫通识口径为基准模板）

皇后 → 皇贵妃 → 贵妃 → 妃 → 嫔 → 贵人 → 常在 → 答应（清代定制）；汉制参考：皇后→夫人→美人→良人→八子（西汉）。

写作要点：位分差一级，待遇差三档（宫例：炭例、份例、宫女太监数、座次、见礼次序）。「位分低而受宠」与「位分高而失势」的错位是宫斗文的基本张力源。

## 二、见礼与避讳（把礼写成武器）

1. **跪安/蹲安**：低位见高位、晨昏定省；让位分高者「免礼」是施恩，故意不让低位者起身是立威。
2. **座次**：一宫主位、筵席位次、轿子让道——场景里谁坐谁站就是权力地图。
3. **称呼**：自称（臣妾是明清剧流变，正史口径妾/嫔妾/奴婢分场合）、他称（娘娘是统称，正式称位分：「贵妃娘娘」）；直呼其名是重罪或极亲昵，两端都可做戏。
4. **避讳**：冲撞主位名讳、御讳，可做大可做小——「欲加之罪」的经典入口。

## 三、日常秩序节点（剧情挂钩点）

晨昏定省（请安迟到＝失仪罪）、内务府份例（克扣炭例是经典冲突引信）、太医请脉（男女大防＋下毒疑云主场）、宫廷宴（座位/敬酒/歌舞安排都是暗战）、祭祀礼仪（主祭权＝摄六宫事的前奏）。

## 四、升位降位的机制（爽点引擎）

- 升位：诞育（皇子/公主）、家世变动（父兄军功）、圣心独宠、代掌宫务。**一次升两级以上必须给足理由**，否则读者出戏。
- 降位：忤逆、巫蛊、失仪、连坐（母族获罪）。降位后「位分还在礼先崩」的细节（旧人不再行礼）最出戏剧感。
- 复位/再起：翻案证据、新帝登基、太后插手。

## 五、常见硬伤清单

1. 位分名号跨朝代混搭（答应/常在是清制，勿入汉唐背景）；
2. 「废皇后」太轻率——历史上废后是动摇国本的政治事件，需要前朝力量配合，不是皇帝一句话；
3. 所有妃嫔随时能面圣——实际召幸/觐见有制度，见不着皇帝本身就是剧情资源（「争的不是宠，是面圣资格」）；
4. 宫女太监当众议论主子——当众处死都有余，写轻了失真；
5. 把「皇后管嫔妃」写成纯压制——中宫是礼法所在，皇后失礼法名义反而被动。
