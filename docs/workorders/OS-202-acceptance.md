## 二、返工原因（OS-202a）：能力图节点点不动

浏览器实测：点「事实内核」节点**毫无反应**——无高亮、无卡片展开、无定位。

根因：`capabilityGraphSvg` 产出的节点是 `<g class="gov-graph-node" data-id=…>`，**没有 `data-gov-action`**；而治理台的整页点击委托只认 `event.target.closest('[data-gov-action]')`。`graph-node` 分支虽写了，却没有任何元素能触发它。

施工方原有测试全绿也没抓到，因为测试只直接调 `capabilityGraphSvg(graph, modules, { selected })` 纯函数，从未模拟点击。

返工后：节点 `<g>` 带 `data-gov-action="graph-node"`、`role="button"`、`tabindex`、`aria-label`；补了 `Enter`／`Space` 键触发；新增三条接线回归测试（本次缺陷的直接护栏）。
