## 任务

1. **`arch-stats` 分层表重写**：从 L1–L7 改为「底座／内核件／工作台／创作套件／磁盘」五行；生成段回写 `ARCHITECTURE.md`。
2. **门禁改写**（旧规则删除要留痕——在检查项注释里写「原 S2.x，OS-184 改写」）：
   - S2.4′（内核实现唯一）→「底座边界」：`src/kernel/**`（或定稿的底座目录）只许含五件宪法的实现；多一个文件都红；
   - S2.1（模块 import 三层路径规则）→「能力路由」：任何插件不得 import 其他插件内部实现，一律经 `resolve(...)`；豁免台账清零（数据驱动的共享纯模块如 `md.mjs` 按定稿处理）；
   - S2.7（端点归属）→「能力归属」：每个能力 N/N 有主，每个端点、页签、slot 有主；
   - 新增「覆盖矩阵测试」：三项启动检查、两条停用语义、四条覆盖守卫各至少一例，列成矩阵表进 `docs/ACCEPTANCE.md`。
