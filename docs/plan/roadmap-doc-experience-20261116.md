# 文档体验路线（三大块，2026-11-16 作者立项）

> 作者要求：**原生 md 作为数据源、组件级实时渲染、沉浸式无框编辑＋元信息；Agent 协同（框选润笔/讨论）；
> 分析套件（剧情曲线/情绪密度/文风/AI 味，可标注可解决）**。参考对象：Pinax web（Electron 渲染层）＋ DeepWrite。
> 原则：**文档渲染好看是基础；简洁易用、功能 UX 友好是关键；多数功能收进右上角设置，页面保持干净。**

## 参考盘点结论（Pinax web / DeepWrite）

| 面 | Pinax 现状 | 我们取什么 |
|---|---|---|
| md 渲染 | `marked@18`+`dompurify`，单出口 `renderMarkdown`；**双链不是插件**，是渲染后 TreeWalker 后处理 | 照抄「单出口＋渲染后 DOM 后处理」；但本仓零 npm → **自研轻量渲染器**（GFM 子集） |
| 编辑器 | `<textarea>` 当纸面（border:none/outline:none/透明底），字号/行高/缩进全走 CSS 变量 | **直接采用**：textarea 纸面 + CSS 变量投影，切换阅读/编辑不跳字 |
| 点入即改 | 渲染容器 `children[n]` ↔ 源码第 n 段起点，`setSelectionRange`＋滚一屏 | 采用（近似算法，不做字级映射） |
| 偏好 | 字号 14–22、行高 1.6–2.4、段距 0–2em、首行缩进 0–2em、打字机、段落聚焦 | 采用前四项（打字机/聚焦后续） |
| 选区动作 | 只存 selectionStart/End；按钮 `mousedown.preventDefault()` 保选区；结果先出预览卡再插入/替换 | **直接采用**（省大量撤销逻辑） |
| 词条 | 蓝链替代高亮；**一个词落两目标就不染** | 高亮用词表＋唯一归属纪律；悬浮卡自研 |
| 历史 | 列表 + 行级 diff + 恢复前快照 | 已有 `.history` 产物中心，补「行级 diff」与「恢复前快照」 |
| 分析 | **没有**情绪曲线/AI 味（只有审查本章卡片） | 全新做（见块三）；DeepWrite 的「文风/多维分析」作口径参考 |
| 章节 | 章号从文件名 `NNN-` 派生，不维护第二份 | 已采用（chapters.mjs） |

## 块一 · 文档渲染与沉浸式编辑

### OS-21（第一批，本单）
1. **`public/md.mjs`** 自研轻量 Markdown 渲染器（零依赖）：标题/段落/粗斜体/行内码/围栏代码/引用/有序无序列表/分割线/链接/转义。输出已转义 HTML（不引 DOMPurify，因渲染器自己只产白名单标签）。
2. **正文页签沉浸式纸面**：去边框/去面板感，居中版心（`--doc-max`），`textarea` 与只读渲染共用同一组 CSS 变量。
3. **元信息栏**：第几章（号）· 标题 · 字数 · 最近修改 · 版本历史入口（→产物中心该文件的历史）。
4. **设置页「外观·写作」节**：正文字号 / 行高 / 段距 / 首行缩进 / 自动隔行（空行间距）——localStorage 持久化，投影为 `:root` CSS 变量。
5. **阅读/编辑双态**：默认阅读态（渲染 md），点正文任意段 → 该段进入编辑（全量 textarea，聚焦到该段偏移）；Esc/点空白 → 回阅读态并保存。

### OS-22（第二批）
6. **条目高亮＋悬浮词条卡**：从 `/api/entries` 取词表（name/aliases，唯一归属纪律），渲染后 TreeWalker 包裹；hover 300ms 出悬浮卡（层级/定义/出现次数/所属书），点击→世界书条目详情。
7. **词条侧栏提示**：本文档命中词条计数，点击筛选高亮。

### OS-23（第三批）
8. **框选浮窗（两选项）**：选中文字上方浮出「润笔 / 与 Agent 讨论」。
   - 润笔：直接把选区＋上下文拼 Agent 请求，结果出**预览卡**（插入/替换/丢弃）。
   - 讨论：把选中段落＋上下文塞进 Agent 左列会话，**对话框上方出现上下文提示条**（可移除），作者补充需求继续聊。

## 块二 · Agent 协同（OS-23/24）

9. 会话上下文提示条（选中段落/章节摘要/词条命中）——可增删的 context chips。
10. 底部「推演」入口与正文打通：以当前章节为语料，产出分支→可选采纳（已有卡机制）。

## 块三 · 分析套件（OS-25～27，复杂功能，分三步）

11. **指标引擎（纯计算，零模型）**：章节/全文的 字数节奏、对白比例、句长分布、段落密度、情绪词强度曲线（词典驱动）、重复度（AI 味代理指标：高频连接词/套话/从句长度方差）。
12. **可视化面板**：章节情绪曲线（SVG 折线＋悬停读数）、多维度雷达、AI 味分解条——全部 SVG viewBox，零图表库。
13. **文档内标注**：指标命中区间 → 文档内高亮（`<mark>` 层，非破坏），侧边气泡注释卡（问题/建议/一键忽略/交给 Agent 改）+ 每条可独立「标记已解决」；标注状态存 `.openstory/analysis/<chapter>/<runId>.json`（不写正文）。

## 共同约束

- 契约先行；daemon 仍只监听 127.0.0.1；写正文一律过 chapter 通道（原子写＋.history）。
- 前端零构建、零 npm：新渲染器/图表一律自研（SVG + 纯函数）。
- 设置项一律收进右上角设置页，工作面保持干净。
