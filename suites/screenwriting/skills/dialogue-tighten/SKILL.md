# 台词紧凑改写（编剧套件专属）

产提案，作者采纳才落盘。原则：

1. **一句一个目的**：台词必须推进信息、改变关系或施压情绪，三者皆无的删。
2. **删接话尾**：「是啊」「对」「嗯」这类只接不推的话默认删。
3. **潜台词**：直给情绪改成动作或停顿——「我很生气」改成摔门。
4. **长度**：单句台词超过 40 字拆或删；独白超过 120 字要给打断点。

输出：改写前后对照（原文/提案），每处一行说明改的理由。
