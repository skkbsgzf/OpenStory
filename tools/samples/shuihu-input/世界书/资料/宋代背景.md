# 宋代背景

水浒传的时代设定：北宋末年（徽宗朝）。

## 关键制度

| 名词 | 说明 |
|---|---|
| **押司** | 县衙书吏，管文书。[[宋江]]的出身 |
| **提辖** | 州府武官，管练兵捕盗。[[鲁智深]]的出身 |
| **教头** | 禁军武师。[[林冲]]的出身 |
| **刺配** | 脸上刺字后流放。林冲、宋江、武松都受过 |
| **生辰纲** | 送权贵的成批礼物。见 [[智取生辰纲]] |

## 地理

- **东京**：开封府，首都。[[高俅]]、[[林冲]]的来处
- **江州**：今九江。[[宋江]]题反诗处，见 [[浔阳楼]]
- **沧州**：今河北。林冲发配地，见 [[山神庙]]
- **阳谷县**：今山东。[[武松]]打虎处，见 [[景阳冈]]
- **梁山泊**：今山东梁山，八百里水泊

## 年号

徽宗朝：建中靖国、崇宁、大观、政和、重和、宣和。

「宣和」是招安前后常用的年号。

## 关联

这些背景不是装饰——**职官决定人物处境**。林冲的教头身份让他必须忍，宋江的押司身份让他懂人情，鲁智深的提辖身份让他敢动手。

已按此设定开笔：仁宗朝瘟疫开篇（史实里是徽宗朝事，说书人故意前挪以早出洪信），见 [[正文/001-第一回 张天师祈禳瘟疫.md|第一回开篇]]。
