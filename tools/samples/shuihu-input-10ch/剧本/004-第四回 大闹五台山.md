# 第一幕 剃度

*〔场景：五台山文殊院，法堂。晨钟。香火极盛，光线从高窗斜切下来。〕*

赵员外在前引路，鲁达跟在后面，一身尘土，行囊只剩一个布包。

**智真长老**（起身）：赵施主。

**赵员外**：长老，这位是我故交，出了人命官司，无处安身。求长老收留。

**智真长老**（看鲁达）：你叫什么？

**鲁达**：鲁达。

**智真长老**：做过什么？

**鲁达**：经略府提辖。

**智真长老**：杀过人？

*〔堂上众僧齐齐抬头。〕*

**鲁达**（沉默一下）：杀过。一个恶霸。

**智真长老**（点头）：恶霸。

*〔他伸手，摸了摸鲁达的头，像在摸一块石头。〕*

**智真长老**：剃。

# 第二幕 法名

*〔场景：法堂。剃刀已下，头发落了一地。〕*

**智真长老**：从今日起，你法名智深。

**鲁智深**（摸了摸光头，忽然问）：长老，酒吃得么？

*〔众僧里有人笑出声。〕*

**智真长老**（平静）：佛门清净，酒肉俱断。

**鲁智深**：断了会怎样？

**智真长老**：断了，你还是智深。断不了，你也是智深。

*〔鲁智深愣住。长老已经转身走了。〕*

**鲁智深**（对着背影）：长老这话，我不懂。

**智真长老**（不回头）：不懂就记着。

# 第三幕 山下

*〔场景：五台山下，市井。午后。酒旗在风里翻。〕*

鲁智深挑着水桶下来，走到一家酒铺前，把桶一放。

**鲁智深**：筛酒来。

**酒保**（打量他的僧衣）：师父，本店不卖酒给寺里的师父。

**鲁智深**：我不是寺里的。

**酒保**：您这一身……

**鲁智深**（把袖子一撸，露出臂上刺青）：我是什么？

*〔酒保看了看那只手臂，把酒坛搬了出来。〕*

**酒保**：师父……少喝些。

**鲁智深**（一碗下去）：再筛。

*〔一连喝了十几碗。日头偏西时，他站起来，脚步晃了一下。〕*

# 第四幕 山门

*〔场景：文殊院山门。夜。灯笼。〕*

鲁智深一步一晃地上来，走到山门前，抬头看那两尊金刚。

**鲁智深**（指着金刚）：你瞪我做什么？

*〔金刚不语。〕*

**鲁智深**：你也瞪我！

*〔他一拳打过去。泥塑的金刚塌了半边。〕*

*〔众僧从殿里涌出来。〕*

**众僧**：师兄醉了！快请长老！

**鲁智深**（转身，看见半山亭）：这亭子也碍眼。

*〔他上去一推。亭子塌了。〕*

*〔众僧退到殿门口，没人敢上前。〕*

**智真长老**（从人群后走出来，声音不大）：智深。

*〔鲁智深回头。〕*

**鲁智深**：长老……

**智真长老**：酒醒了么？

**鲁智深**（站着，晃了一下，忽然跪下去）：长老，我断不了。

# 第五幕 荐书

*〔场景：方丈室。夜。一盏灯。〕*

智真长老研墨，写了一封信，封好，推到鲁智深面前。

**智真长老**：这寺容你不得了。

**鲁智深**（低头）：我走。

**智真长老**：我有一封书，荐你去东京大相国寺，投智清禅师。他是我师弟。

**鲁智深**（接过信，捧着）：长老……

**智真长老**（挥手）：去吧。

*〔鲁智深起身，走到门口，停住。〕*

**鲁智深**：长老，我砸了金刚，推了亭子，你怎么不赶我下山，还给我写信？

**智真长老**（吹熄灯）：因为我看见你跪下了。

*〔黑暗里，鲁智深站了很久。〕*

# 第六幕 桃花庄

*〔场景：桃花庄，庄门。夜。门上贴着红纸。〕*

鲁智深投宿到庄上，庄主刘太公面色不好。

**刘太公**：师父，本庄今夜有事，不便留客。

**鲁智深**：什么事？

**刘太公**（叹气）：小女被山上的强人要娶。今夜就要来。

**鲁智深**（坐下）：那正好。我替你入帐。

**刘太公**：这……

**鲁智深**：你女儿躲了。帐里我去。

*〔夜半。新房。红烛。鲁智深坐在帐中，把被单一掀，盖住头。〕*

*〔门被推开。一个胖大汉子摸进来，一身酒气。〕*

**周通**（笑着，摸黑）：娘子……

*〔他摸到一手硬肉。〕*

**周通**：咦？

*〔被单一掀，一只拳头打在他脸上。〕*

**周通**（惨叫）：哎哟！

**鲁智深**（骑上去，一拳一拳）：你要娶谁？你要娶谁？

**周通**（抱着头滚）：好汉饶命！

**刘太公**（提灯冲进来）：师父！别打了！这是桃花山二头领周通！

**鲁智深**（停下，喘）：强人？

**刘太公**：是……是……

**鲁智深**（把周通提起来）：你听好。

**周通**：听……听好。

**鲁智深**：这门亲，退了。

**周通**：退！我退！

**鲁智深**（放手）：滚。

*〔周通连滚带爬出去了。〕*

*〔次日。刘太公送他到庄口。〕*

**刘太公**（捧着布包）：师父，这是些盘缠……

**鲁智深**（不接）：我打了人，你还要谢我？

**刘太公**：师父救了我一家……

**鲁智深**（笑，把布包推回去）：留着给你女儿做嫁妆。

*〔他挑起行李，往东京去。〕*

*〔正是：醉打山门难容身，一封荐书向东京。〕*

*〔毕竟智深到相国寺如何，且听下回分解。〕*
