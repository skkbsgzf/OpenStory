# 第一幕 茶坊

*〔场景：渭州，城中茶坊。午后。茶烟腾腾。〕*

史进背着包裹走进来，一身尘土。他找了个靠门的座位，把包裹放在脚边。

**史进**（对茶博士）：借问一声，经略府可有个王进教头？

**茶博士**：王进？没听说。倒是府里有个鲁提辖，最爱管闲事，你问问他。

*〔旁边一个高大的汉子放下茶碗。〕*

**鲁达**：你找王进做什么？

**史进**（起身）：他是我师父。

**鲁达**（上下看他）：你师父？王进使棒，一根棒能挑落三个人。你会什么？

**史进**：我会的，是师父教的。

**鲁达**（笑）：好。坐下，吃茶。我请你。

*〔他招手，茶博士又上了一壶。〕*

# 第二幕 隔壁

*〔场景：酒楼，雅间。傍晚。〕*

鲁达、史进、李忠三人吃酒。隔壁传来哭声，一阵一阵，压得人吃不下。

**鲁达**（把杯子顿在桌上）：什么人在哭？

*〔他起身，掀开隔壁门帘。金老汉父女俩缩在墙角。〕*

**鲁达**：你们哭什么？

**金老汉**（跪）：好汉饶命……

**鲁达**（把他扶起来）：我不是来打你的。说。

**金老汉**：小人姓金，带了女儿翠莲来渭州投亲，亲戚没了。城里有个郑屠，号镇关西，强要了小女做妾，写了三千贯典身钱。如今又翻脸，把小女赶出来，反过来追那三千贯。

**鲁达**：典身钱？一个子儿给了吗？

**金老汉**：一个子儿没给。

*〔鲁达静了一下。〕*

**鲁达**：他如今在哪？

**金老汉**：状元桥下，卖肉的。

# 第三幕 银子

*〔场景：酒楼雅间。〕*

鲁达从怀里摸出五两银子，放在桌上，回头看史进。

**鲁达**：兄弟，借我些。

**史进**：哥哥说什么借。（摸出十两放上）

**鲁达**（看李忠）：你呢？

**李忠**（犹豫，摸出二两）：我……我这就这些。

**鲁达**（把二两推回去）：你也算个不爽利的。

*〔他把十五两推到金老汉面前。〕*

**鲁达**：拿了。今夜就走。

**金老汉**（手抖）：好汉，这……郑屠那边……

**鲁达**：郑屠那边，我明日去会他。

**金老汉**：好汉，他有钱有势……

**鲁达**（打断）：我明日去会他。

*〔金老汉磕了三个头，扶着女儿走了。〕*

*〔史进看着鲁达。〕*

**史进**：哥哥，你明日真去？

**鲁达**（把碗里的酒一口喝干）：我今日就想去。

# 第四幕 肉案

*〔场景：状元桥，郑屠肉铺。晨。案上摆着半扇猪。〕*

鲁达走进铺子，往案前一站。

**鲁达**：郑屠。

**郑屠**（抬头，堆笑）：鲁提辖！今日要什么？

**鲁达**：精肉十斤，切成臊子。

**郑屠**：好嘞。（回头喊）来，给提辖切！

**鲁达**：你自己切。

*〔郑屠愣了一下，笑着挽起袖子。切了半个时辰。〕*

**鲁达**：再要肥肉十斤，也切臊子。

**郑屠**（擦汗）：提辖，这肥肉切臊子，没这么吃的。

**鲁达**：我吃。

*〔郑屠忍着，又切了半个时辰。额上汗滴到案上。〕*

**鲁达**：再要软骨十斤，细细剁了。

**郑屠**（把刀往案上一拍）：提辖！你这不是买肉，是消遣我！

**鲁达**（把肉臊子抓起来，劈面掷去）：我今日就是来消遣你的。

*〔肉臊子糊了郑屠一脸。郑屠抄起案上的剔骨刀，扑上来。〕*

# 第五幕 三拳

*〔场景：状元桥，肉铺门前。街上行人停住。〕*

鲁达一脚踢在郑屠胸口，人倒下去，刀飞了。

*〔他跨上一步，提起拳头。〕*

**鲁达**（第一拳）：这一拳，为金老汉卖了女儿！

*〔打在鼻上。血淌下来。〕*

**郑屠**（含糊）：打得好……

**鲁达**（第二拳）：这一拳，为你赖那三千贯！

*〔打在眉际。眼珠迸出。〕*

**郑屠**（声音低了）：你……

**鲁达**（第三拳）：这一拳，为渭州城没王法！

*〔打在太阳穴上。郑屠挺在地上，动了不得。〕*

*〔街上全静了。鲁达站在那儿，看着自己的拳头，又看着地上的人。〕*

**鲁达**（低声）：我只指望打他一顿……

*〔他抬头，看了看四周。围观的人已经开始往后退。〕*

**鲁达**（后退一步）：不想三拳真个打死了。

*〔他转身，快步走。走了十几步，忽然跑起来。〕*

# 第六幕 出城

*〔场景：渭州城南门，官道。黄昏。〕*

史进在城门外等着。见他来了，把包袱递过去。

**史进**：马备好了。

**鲁达**（接过，喘）：你怎么知道我要走？

**史进**：三拳打死人，还能不走？

*〔鲁达笑了一下，笑得很短。〕*

**鲁达**：我这一辈子，最恨两件事。一件是仗势欺人，一件是见死不救。

**史进**：哥哥两件都占了。

**鲁达**（沉默，然后拱手）：兄弟，就此别过。

**史进**：哥哥去哪？

**鲁达**：天大地大。（翻身上马）走一步看一步。

*〔马去了。史进站在城门外，看着那条路。〕*

*〔正是：提辖三拳除恶霸，避难削发上台山。〕*

*〔毕竟鲁达到五台山如何，且听下回分解。〕*
