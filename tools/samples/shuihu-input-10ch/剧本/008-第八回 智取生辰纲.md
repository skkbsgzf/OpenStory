# 第一幕 投名状

*〔场景：梁山泊，聚义厅。晨。厅中只坐三人。〕*

王伦坐在上首，杜迁、宋万在下首。林冲站在厅心。

**王伦**（拿着一把折扇，慢慢摇）：林教头远来，本该好好招待。只是——

**林冲**：只是什么？

**王伦**：只是山寨粮少房稀。教头这一身本事，怕委屈了。

**林冲**（不说话，看着他）。

**杜迁**（低声）：哥哥，林教头是柴大官人荐来的……

**王伦**（扇子一合）：我知道。（转向林冲）教头若肯留，可先纳一份投名状。

**林冲**：投名状是什么？

**王伦**：下山去，杀一个人。

*〔厅里静下来。〕*

**林冲**（半晌）：三日。

**王伦**（笑）：三日。

# 第二幕 山下

*〔场景：梁山泊山下，山道。三日。晴。〕*

第一日。林冲藏在树后，看见一个挑着担子的货郎过去。他把刀收了。

第二日。一个老妇人扶着孩童走过。他把刀收了。

第三日。日头偏西。林冲靠在一棵松树上。

**林冲**（自语）：我林冲杀了陆谦，杀了富安，杀了差拨。那三个人，是该死的。

*〔他低头看刀。〕*

**林冲**：可这个人，不该死。

*〔他正要把刀插回鞘里。山道尽头来了一个人。〕*

*〔那人挑着担子，一身青衫，脚步极稳。走到近前，忽然停住。〕*

**杨志**（放下担子，看着她）：朋友，躲了三日了，出来罢。

*〔林冲从树后出来。〕*

**林冲**：你怎么知道我躲着？

**杨志**：这山道我走过。此处有三棵树被压弯了，是有人久靠。

**林冲**（打量他）：你要过这条道？

**杨志**：我要过。你要拦？

**林冲**：我要一份投名状。

**杨志**（把担子往地上一放，从担里抽出朴刀）：那你得先问它。

# 第三幕 四十合

*〔场景：山道。两人交手。〕*

*〔刀来枪往，打了四十余合，不分胜负。〕*

*〔林冲的刀法越来越沉。杨志的朴刀越来越稳。〕*

*〔忽然山道上一声喊。〕*

**王伦**（带人赶来）：住手！都住手！

*〔两人分开。各自喘息。〕*

**王伦**（看清杨志，脸色一变）：这位……是杨制使？

**杨志**（收刀）：你认得我？

**王伦**（堆笑）：杨制使是殿司制使，谁不认得。（转向林冲）教头，这位是自己人。

**林冲**（看着王伦的脸）：自己人？

**王伦**（笑）：都是好汉，何苦相并。走走走，上山吃酒。

*〔他一手拉着杨志，一手招呼林冲。〕*

*〔林冲站在原地，把刀收了。他看着王伦的背影，什么也没说。〕*

# 第四幕 押纲

*〔场景：北京大名府，梁中书府。书房。〕*

梁中书把一封文书推过来。

**梁中书**：十万贯生辰纲，上东京，给蔡太师贺寿。谁去？

*〔堂下无人应声。〕*

**梁中书**（看杨志）：杨志。

**杨志**（出列）：在。

**梁中书**：你去。

**杨志**（沉默一下）：小人愿往。只是小人有一句话。

**梁中书**：说。

**杨志**：这一路，须听小人调度。军汉不得违令，押送的虞候不得插嘴。

*〔梁中书旁边的谢都管脸一沉。〕*

**谢都管**：杨志，你这是什么话？

**杨志**（不看他）：都管若不信小人，另请高明。

*〔梁中书看了看两人，把文书往前一推。〕*

**梁中书**：依你。

# 第五幕 黄泥冈

*〔场景：黄泥冈，松林。正午。日头毒。〕*

十五个军汉挑着担子，一个个瘫在松树底下。

**军汉甲**（喘）：杨提调……实在走不动了……

**杨志**（拿藤条抽地）：起来！此是险地，岂能歇脚！

**军汉乙**（低声）：这厮拿我们当牲口。

**谢都管**（坐在树上，扇着扇子）：杨志，我说句公道话。这天气，人是要走的。

**杨志**（回头）：都管忘了出发前的话？

**谢都管**（把扇子一收）：我只是劝你。

*〔松林那头，七个贩枣客人挑着担子上冈来。〕*

*〔领头的一个汉子，面皮白净，一路走一路说笑。〕*

**贩枣客甲**（放下担子，抹汗）：这鬼天气。各位也是赶路的？

**军汉甲**：赶路的。累死了。

**贩枣客甲**：我们带了酒。（朝冈下喊）卖酒的！上来！

*〔一个汉子挑着两桶酒，晃晃悠悠上了冈。〕*

**军汉甲**（眼睛亮了）：酒！

**杨志**（一步跨过去）：且住！

# 第六幕 一桶

*〔场景：黄泥冈，松林。〕*

*〔卖酒的把桶放下。军汉们围上去。〕*

**军汉甲**：多少钱一桶？

**卖酒的**：五贯。

**军汉**：五贯就五贯！

**杨志**（把军汉拨开）：这酒来得蹊跷。

**贩枣客甲**（笑）：蹊跷？我这几个兄弟先吃给你看。

*〔他舀了一瓢，几个贩枣客人轮流喝下去。喝完，抹抹嘴，什么事也没有。〕*

**贩枣客甲**：你看，没事。（又舀一瓢）这位提调，也尝一口？

**杨志**（看着他们，又看看那些瘫着的军汉，犹豫）。

**军汉甲**（已经抢过瓢）：我先喝！

*〔一瓢下去。接着是第二瓢，第三瓢。〕*

**杨志**（看着军汉们喝，终于接过贩枣客递来的一瓢）：……就半瓢。

*〔他喝了。酒很甜。〕*

*〔甜得不对。〕*

**杨志**（把瓢一放，抬头）：不对——

*〔话没说完。眼前一黑。〕*

*〔七个人动了。他们把担子挑起来，往冈下走。走得很快，没有一个人回头看。〕*

*〔松林里，十五个军汉横七竖八倒着。〕*

# 第七幕 醒来

*〔场景：黄泥冈，松林。傍晚。〕*

杨志睁开眼。日头已经偏西。他撑着坐起来，看见空了的担子，看见那些倒着的军汉。

**杨志**（站起来，踉跄）：生辰纲……

*〔他奔到担子边，翻开。空的。〕*

**杨志**（跪下去）：十万贯……

*〔他忽然抓住自己的头发。〕*

**杨志**：我杨志，三代将门之后。

*〔他抬头看天。〕*

**杨志**：三代将门之后啊！

*〔他把腰刀抽出来。刀映着西边最后一点光。〕*

*〔他看了很久，然后把刀往自己颈上按。〕*

*〔一棵松树后面，有人开口。〕*

**曹正**（拄着刀）：要死，也得先找着人。

*〔杨志回头。〕*

**杨志**：谁？

**曹正**（走出来，是个屠户打扮的汉子）：操刀鬼曹正。我在冈下看见那七个人了。

**杨志**（握刀）：他们在哪？

**曹正**：他们往石碣村去了。（顿了顿）不过你这一身功夫，去送死？

**杨志**（站起来）：我丢了生辰纲，回去也是死。

**曹正**（点头）：那就换个地方。

**杨志**：什么地方？

**曹正**：二龙山。

*〔他指了指西边。〕*

**曹正**：那里的头领，跟你有得谈。

*〔杨志把腰刀插回去。他站着，看了一眼东边的路——那是回北京的路。然后他转向西边。〕*

*〔正是：杨志押纲遭劫，梁山又添愁人。〕*

*〔毕竟杨志性命如何，且听下回分解。〕*
