# 第一幕 京师求雨

*〔场景：东京紫宸殿，早朝。殿外天色昏黄，丹墀下百官分成两列，无人抬头。〕*

殿头官拂尘一摆，声音在殿梁间撞了几个来回。

**殿头官**：有事出班早奏，无事卷帘退朝。

班部中静了片刻。宰相赵哲先出，参政文彦博随后，两人在御前三步站定，一同伏地。

**赵哲**：臣等有罪。京师瘟疫已及三月，军民死者不可胜数，臣等不能调和阴阳，请陛下治罪。

**仁宗**（扶额，声音低）：朕要的不是治罪的话。

**文彦博**：眼下有两件事可做。一是降赦天下罪囚，民间税赋一概宽免；二是命在京宫观寺院修设好事，禳此天灾。

**仁宗**：准。快去办。

*〔半月后。殿门半掩，帘外日光惨白。仁宗独坐，案上药碗已凉。〕*

**仁宗**（把药碗推开）：瘟疫转盛了？

**内侍**：回陛下……今日报上来的，比上月还多了三成。

*〔满殿无人应声。范仲淹出班。〕*

**范仲淹**：陛下，臣有一策。

**仁宗**：说。

**范仲淹**：此非药石可治。臣愚见，须宣嗣汉天师星夜临朝，就京师禁院修设三千六百分罗天大醮，奏闻上帝，方可禳保民间瘟疫。

**仁宗**（沉吟）：天师……在江西龙虎山？

**范仲淹**：正是。臣荐一人为使——殿前太尉洪信。此人奉旨从未有过差池。

**仁宗**：准奏。宣洪信。

*〔洪信趋步入殿，衣甲未卸，甲片在殿砖上磕出细响。〕*

**洪信**（跪）：臣在。

**仁宗**：朕命你为天使，往江西信州龙虎山，宣请嗣汉天师张真人星夜临朝。不得有误。

**洪信**：臣，领旨。

*〔洪信起身退出，走到殿门时回望一眼。殿上无人看他。〕*

# 第二幕 上清宫

*〔场景：龙虎山上清宫山门外。石阶湿滑，松声如潮。〕*

洪信一行到时，山门已开。住持真人领着两列道士候在阶下，合十行礼。

**真人**：天使远来，一路辛苦。

**洪信**（拱手，四下看）：天师何在？

**真人**：天师性好清高，倦于迎送，自向山顶结茅庵居止。

**洪信**（皱眉）：我奉圣旨而来，他竟不来迎？

**真人**：天使若要见时，须是自去。

**洪信**：自去？

**真人**：斋戒沐浴，更换布衣，休带从人，步行上山。

*〔洪信沉默片刻。山风穿过松林，把他袖口吹起来。〕*

**洪信**（低声）：圣旨在身……

**真人**：天师面前，圣旨也只是一张纸。

*〔洪信猛地看他，真人神色不动。〕*

**洪信**：好。依你。

*〔次日五更。洪信换了一身粗布，草履，独自站在山道口。天光还暗，山道往上看不见尽头。〕*

**洪信**（自语）：我做了二十年官，何曾一个人走过山路。

*〔他抬脚，往上走。〕*

# 第三幕 虎与蛇

*〔场景：龙虎山半山。雾。松石间只闻脚步。〕*

行不到半里，山道旁忽有一物直起。

*〔一只吊睛白额锦毛虎，双目如灯，望着洪信扑将来。〕*

**洪信**（惊倒，声音破）：啊——！

*〔他伏在石上，闭眼，只听得风声、虎息。良久，什么也没发生。〕*

*〔洪信睁眼。虎不见了。石面上留着一枚爪印。〕*

**洪信**（撑起身，手在抖）：假的……一定是假的……

*〔他正待要走。怪风过处，竹影里跳出一条吊桶大小、雪花也似的大蛇来，直抢到面前。〕*

**洪信**（跌坐）：又来！

*〔蛇盘作一堆，吐着信子看他。山雾在它身侧流动。〕*

*〔过了不知多久，那蛇也去了。〕*

洪信连遭两吓，衣上泥水，坐在地上再也站不起来。他从怀里摸出圣旨，看了一眼，忽然笑了。

**洪信**（笑）：我洪信……竟然怕成这样。

*〔他把圣旨塞回去，爬起来，往下走。〕*

# 第四幕 伏魔殿

*〔场景：上清宫后殿。暮色。殿门上封皮层层，朱印累累。〕*

**真人**（迎上）：天使回来得好。

**洪信**（摆手）：山上有虎，有蛇。你早知道。

**真人**：那是天师试探。非真虎蛇。

**洪信**（冷笑）：试探。好一个试探。

*〔他不走，闲步往后殿去。走到一所殿宇前停住。门上贴着一道封皮，层层叠叠，朱印累累。〕*

**洪信**：此是何殿？

**真人**（快步过来）：此乃唐朝洞玄国师镇压魔王之所，凡遇此殿，不可擅开。

**洪信**：不可擅开？

**真人**：不可。

**洪信**（回头看他）：天师试我，你也试我？

**真人**：不敢。

**洪信**：那我今日偏要看看，这殿里锁的是什么东西。

**真人**（合十，急）：天使！此殿万万不可！

*〔洪信不答。他走到门前，伸手，一层一层揭那封皮。朱印碎裂，落在地上。〕*

**真人**（顿足）：天使——！

*〔封皮尽裂。洪信双手推门。〕*

*〔一声响亮，好似天摧地塌，岳撼山崩。黑烟起处，一道黑气从殿中冲出，直上半天，散作百十道金光，望四面八方去了。〕*

*〔殿前的人都僵住了。〕*

**洪信**（面如土色，后退两步）：这……这是什么。

**真人**（跌坐在地，声音发颤）：太尉，你误了大事。此殿中锁的，是一百单八个魔君。

**洪信**：魔君？

**真人**：一百单八个。如今被你放将出去……

*〔他抬起头，看着洪信。〕*

**真人**：如之奈何？

*〔洪信不说话。他把袖子一拂，转身就走，脚步越来越快。〕*

# 第五幕 回京

*〔场景：上清宫山门外，夜。灯笼两盏。〕*

**洪信**（对随从）：走。即刻走。

**随从**：太尉，天还没亮……

**洪信**：我说走。

*〔他上马，不看后方。灯笼的光圈在马蹄旁摇晃。〕*

*〔半山之上，真人立在阶前，望着那点火光往山下走，终于看不见。〕*

**真人**（低声）：一百单八人，散在四方。

*〔他转身回殿。身后是那扇再关不上的殿门。〕*

**真人**：或为官，或为吏，或为僧道，或为商贾。

*〔山风把他的话吹散了。〕*

*〔后来这一百单八人，散在四方。一似：一朝云雨会，终作栋梁材。〕*

*〔毕竟不知这一百单八人果是何等样人，且听下回分解。〕*
