# 文风复刻 · 异兽迷城（彭湃）

> 蒸馏底账：正文 1306 章 / 304 万字全量统计（非抽样）。原始材料：`C:\Users\Administrator\D盘归档\写作\写作\04_风格蒸馏\异兽迷城-彭湃\`（Writing-DNA / 语言DNA / 文章结构模板 / 写作视角与认知框架 ＋ raw 逐章）。
> **一句话识别度**：用一句一换行的短句、生活物什和身体感官，把温情日常当场砸碎成恐怖悬念——读者跟着主角一起「说不清哪怪异」。

## L1 语言指纹（最强，可判真伪）

1. **短句＋一拍一段**：平均句长 ~23 字，43% 句子 ≤15 字，26% 段落就是半句话。强调句、转折句、恐怖点**独立成段**。禁连续三句等长复句。
2. **对话驱动**：对白约占 1/4，配「说道/问道/笑着说/点点头」＋神态；称呼即情感坐标（队长/爸爸）；寒暄删。
3. **时间词卡点**：很快 / 几秒后 / 两秒后 / 忽然 / 一时间——推节奏与悬念；但别每段同一个词，打散。
4. **拟声成句成段**：「砰！」「噗通、噗通、噗通噗通噗通……」独立出现。
5. **标点纪律**：单独一行「……」＝场景/时空切换符，**必留**；省略号兼表声音延续、欲言又止；破折号克制（拟声拉长「磁——」）；只用中文引号。

## L2 结构模板

- **单章骨架**：生活白描落位（1–3 句，用具体物什锚时代感）→ 短段动作/对白连击 → 章内转折（梦境/回忆/配角 POV，前后各一行「……」）→ 章末抛新疑问或危机，**绝不总结升华**。
- **开篇范式「先暖后碎」**：家庭日常把心捂热，一句硬转（「直到这天，一切都改变了」）砸进危机。
- **多 POV**：切入即重锚「时间＋地点＋人」，用物白描不用说明文；只取情绪/回忆层，不借配角之口做全知解说。
- **设定投放**：新硬名词（序列/命格/天赋）**首现即入场景、不解释**，后文拼图；禁开篇设定说明书。

## L3–L5 视角与价值观

- 视角：紧贴主角的限制第三人称，读者信息 ≤ 主角，保留「讲不清的怪异感」；切入偏「事件中途」——从一碗面、一声响开始，不从背景讲起。
- 取材：可触摸日用品承载阶层/亲情/荒诞（冰棍、黑白电视、对坟山的廉租房）；恐惧用五感写，不用心理独白解释。
- 价值底座：「存在过就是存在过，爱过就是爱过，不因被遗忘而消失」；平凡幸福是最高争夺物；不轻用复活死角色。
- 情绪地形：**日常温情 ⇄ 突发残酷高频反差交替**，不是单线爽感。

## 复刻纪律

1. 原文具体情节、人名、设定**不得搬进新文**——复刻写法，不复刻内容。
2. 动笔前从 raw 语料抽读 2–3 章校准语感；写完对照 L1 五条指纹自检（短句/换行/「……」转场/时间词/对话密度）。
3. 指纹冲突时优先级：用户本次指令 > L2 结构 > L1 语言 > L3–L5 视角价值观（视角层决定立场与取材，不决定句式）。
