# 文风延续红线（写下一章前必读）

## 一、延续规则

1. **动笔前必须精读紧邻前 2-3 章**（含上一章人物状态）——文风一致靠延续前文，不靠自我发挥。
2. 用户本轮明确的文风指令优先于本规范；没有指令时严格延续既有文风。
3. **引号字符级规则**：全文统一中文弯引号「」或 ""（选定后不混用），逐字符对齐相邻正文。

## 二、量化工艺基准

| 项 | 基准 |
|---|---|
| 开场手法 | 从「拟声／反刍／吐槽／反问／动作锚定」库中选一种，**不与上一章同款** |
| 章末钩子 | 从「特写意象／宣言／未竟省略号／身份揭晓／吐槽／金句／音效／生理反应／选择」库中选一种，**不与上一章同款** |
| 省略号密度 | 8—15 个/章（心理留白与未竟之语） |
| 破折号 | ≤2 个/章 |
| 感叹号 | ≤3 处/章 |
| 对白段落占比 | 40%—55%，每段对白带动作或神态锚 |
| 段落长度 | 以 1—2 行为主，均值≈38 字；**禁止 4 行以上大段**；禁止 200 字连续设定说明 |
| 现代梗/行业黑话 | 一章最多 1—2 处，必须自嘲式 |

## 三、六条工艺手法

1. **场景转换/首次进入新地点**：用**物件扫描镜头**——逐件白描，停在异常物上。
2. **设定注入用记忆流列表**：每条一行，省略号风格；**禁止旁白讲史**。
3. **大场面台词用切分法**：悬念半句 → 段落停顿 → 独立成段揭晓。
4. **台词讲解必须藏在戏里**：交易/审问/授课等场景承载信息，不单开「讲解段」。
5. **章末单句钩子收尾**；开场与章末手法与上一章不同款。
6. **数字要具体**：资源量、时间、倍数——能给可引用数字就不写「很多」。

## 四、硬红线

- **禁止**网络流行语与现代都市词（角色内心吐槽的行业黑话除外，且须自嘲式）。
- **禁止**译制腔与洋气称谓/货币（「哦，我的老伙计」式表达）——那是外壳，不是骨。
- **禁止**旁白解释人物动机；动机用行动、选择、可感知细节呈现。
- **文体不可混**：祷文/诗词一律韵文腔，公文体/指令一律白话公文，不得混体。
- 诗词成语可用，网络流行语不可用。

## 五、每章自检

- [ ] 朗读一段新写内容，与「文风画像」范文锚点比对：句子长度节奏、吐槽密度、比喻取材是否一致。
- [ ] 章末是否单句钩子收尾；开场/章末是否与上一章重复同款。
- [ ] 数字是否具体。
- [ ] 对白占比、省略号与破折号配额是否在区间内。
- [ ] 有无 4 行以上大段或 200 字连续设定说明。
