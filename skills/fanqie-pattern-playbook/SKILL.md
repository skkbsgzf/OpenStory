# 番茄短篇套路手册

> 数据底账：16 本 / 23.4 万字，S 级 15 本，第一人称 14 本。每章 1700–2800 字（中位 1930），伏笔密度 1.41 条/千字（约每 700 字一个）。

## 硬统计（写前先对表）

| 维度 | 结论 |
|---|---|
| 结构母型 | 逆袭升级＋复仇＝75%。短篇只有两个母引擎；辅引擎（倒钩回归/双线交叉）供反转 |
| 开局钩子 | 三件套必齐：身份落差＋悬念＋反常；危机开局是加强件 |
| 情绪承诺 | 甜爽过半；疑/痛是高风险高回报档 |
| 首章功能 | 必须「建立」（人物＋处境＋异常），例外是开篇即揭露 |
| 末章功能 | 必须是「揭露」或「打击」，不能温吞收束 |
| 章情绪分布 | 痛 31 > 疑 23 > 燃 17 > 甜 17 > 悔 16 > 爽 4——痛是主旋律，甜文也靠痛垫底 |
| 主角模式 | 觉醒者或镜像施害者二选一 |
| 对立关系 | 多数压迫不写「敌对」边——用夫妻/亲属/师徒这些关系名本身承载压迫 |
| 场景 | 家庭内景压倒性第一；平均 5–10 个场景 |
| 道具 | 证据类道具（手机/录像/监控/日记）是揭露引擎 |
| 标题 | 「X 后，他就 Y 了」事件后转折式最稳 |

## 五个套路模板

### A · 错认身份型（最高频，5/16）
主角自认位置（假千金/实习生/前妻）与真实身份有落差 → 全世界按错误位置对待 → 揭穿时态度反转。
节奏：身份错置 → 压迫成立（写在亲密关系里）→ 反常裂口（做一件与位置不符的事）→ 代价加码 → 真相对账（第三方证据）→ 反转清算（主角已抽身）。
硬参数：6 章 × 1900 字，伏笔 14 条，情绪序 疑→痛→燃→痛→甜→悔。

### B · 弹幕/系统剧透型（3/16）
超前信息源 → 常识方 vs 剧透方的信息差 → 反向操作。
关键：第 1 章就亮信息源；**必须让「常识方」真的嘲笑成功一次**；结局必须揭露「剧透有人操纵」，最后一击靠主角自己的判断而非信息源。

### C · 追妻火葬场型（4/16，注意：标签已在失效，只有「她真的走了」变体有效）
常态压迫写成日常 → 临界事件（不可逆）→ **静默抽离（前 2 章内必须出现，这是全套路的钩子）** → 对方失控 → 证据成形 → 最终对账（情感上已不在场，追不回来）。
情绪全程痛，甜只作回忆闪回。

### D · 双向暗恋错认型（2/16）
双向错认（不是单向）→ 甜痛交替（每次接近同时推进「更爱」与「更确定对方不爱我」）→ 第三方催化 → 失控告白 → 真相对称瓦解。
甜密度最高（≥4 章）；爽感来源＝读者知道而角色不知道。

### E · 摆烂反套路型（2/16）
强制剧本 → 主动作死 → 作死反而刷进度 → 规则加码 → 发现摆烂被设计 → 跳出棋盘（破局靠看穿规则，不靠变强）。
爽点必须「荒诞」，不能是常规打脸；主角＝镜像施害者（自我伤害式反抗）。

## 六条公共规律

1. **首章建立，末章揭露/打击**；中间是铺垫×叠加×对峙的轮转，每 3 章必须有一次揭露（揭露占比 ≈21%）。
2. **痛是主旋律，甜是糖衣**——甜让痛可入口，真正的酬劳是「夺回位置」。
3. **压迫写在最亲密的关系名里**——用最亲的关系承载最狠的压迫，是短篇的核心暴力美学。
4. **证据道具是揭露引擎**——每个揭露章背后都有一个可指认的物证。
5. **反抗不是变强，是「抽离」**——主角赢的方式是「我不玩了」（不闹/离婚/摆烂/消失），抽离本身就是最强的攻击。
6. **信息不对称是硬通货**——每本 4–6 条知情台账；弹幕/心声/系统三种金手指统一内核都是信息差的具象化。

## 一句话题材公式

```
【错位置】的主角，拿到【信息差】，
在【亲密关系】里被【隐性压迫】，
用【抽离】而非【变强】完成【揭露式清算】。
结局：压迫者态度反转，主角已不在场（或已重建位置）。
```
