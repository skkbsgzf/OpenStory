# 文风复刻 · 上交国家（都市脑洞·国家队上交流）

> 蒸馏底账：全本 111 万字 / 498 章全量统计（非抽样）。语料：`番茄下载器 save_dir/系统任务太难？国家：放着我来.txt`。
> **一句话识别度**：系统要抹杀宿主，宿主反手把系统上交国家——个人 bug 变国家级资产；体制不是背景板，是「半开玩笑的中年处长」式温情大后方。

## L1 语言指纹（硬统计，可判真伪）

| 指标 | 数值 | 解读 |
|---|---|---|
| 平均句长 | 30 字 | 中长 |
| 短句 ≤15 字占比 | 21.2% | 叙述从容 |
| 逗号每千字 | 49.4 | 全库偏低——叙述不堆逗号 |
| 对话占比 | 24.5% | 对白带生活颗粒（「陈叔，你这椅子怎么不用了？」） |
| 感叹号每千字 | 4.4 | 系统任务与吐槽拉高 |

- 强指纹三条：①**系统面板直投**（【宿主：李策】【任务进行中，剩余时间：7小时36分45秒】【失败惩罚：抹杀】——信息用方括号面板，不用旁白解释）；②体制温情化（中年处长第一句话是半开玩笑抱怨午休没了；办公室是主卧改的、躺椅落灰）；③脏话解压（「妈的」「狗日的系统」——普通人面对超常压力的真实颗粒）。
- 开场范式：【】标签块＋好消息/坏消息对仗梗（好消息！有系统！坏消息！系统出 bug 总想弄死我！）→ 第 1 章任务倒计时+主角蹲在公安厅对面抽烟——金手指与解决路径同屏亮相。

## L2 结构模板

- **单章骨架**：任务/研究推进（面板+实验）→ 与体制人物的日常互动（办公室生活流）→ 一次小成果或小危机 → 章末任务进度条刷新。
- **上交流范式**：主角发现金手指风险 → 不藏不掖直接报国 → 体制方「半信半疑→验证→惊动上级」三级反应 → 双方建立信任流程（谈一次/测一次/签一次）。
- **人物成长慢热范式**：主角能力按任务等级逐级解锁（初级→……），每次升级伴随心态变化（恐惧→依赖→掌控）；国家线并行推进（处级→厅级→更高层知晓）。
- **生活流配比**：每 3-4 章任务戏之间插一章纯生活戏（陈叔的躺椅/食堂/家属院）——慢热是本包节奏底色。

## L3–L5 视角与价值观

- 视角：第三人称贴主角；体制人物 POV 短切入展示国家视角的震惊与谨慎。
- 取材：体制单位写实（公安厅/国安/保密流程/编制），金手指设定自洽（系统任务可量化：剩余时间/奖励/惩罚）。
- 价值底座：**个人与国家的双向奔赴**——主角上交的是风险也是诚意，国家接住的是资产也是人；「聚焦主角人物成长与国家双向奔赴」是本书自述定位。
- 情绪地形：任务紧张 ⇄ 体制温情日常交替；爽点是「国家给我兜底，我给国家开挂」。

## 复刻纪律

1. 原文情节/人名不搬；系统面板字段自设计，任务规则要可量化。
2. 指纹自检：面板直投在用、体制人物带生活颗粒、每 3-4 章一次生活戏、慢热升级。
3. 优先级：用户指令 > L2 结构 > L1 语言 > L3–L5；涉密单位描写按平台规范虚化。

## 未覆盖（如实交底）
