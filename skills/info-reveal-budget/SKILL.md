# 信息投放边界管理

## 原则
- 读者不知道的比知道的多才对；每次只揭一层。
- 揭示必须绑定高情绪节点（死亡/大战/背叛），不要用对话干讲。
- 每次揭示都要回收前面的伏笔，同时抛出新的追问。

## 分层排期（不可提前）

开工前先建一张自己的表，列出全书 4-6 层真相与各自的揭示时机（示例结构）：

| 层级 | 真相 | 揭示时机 |
|---|---|---|
| L0 | 世界的底层规则（类型承诺） | 第 1 章或前 3 章内 |
| L1 | 主角能力/身份的真相 | 卷一内 |
| L2 | 组织或体制的真相 | 卷二末 |
| L3 | 更大世界的真相 | 卷三末 |
| L4 | 关键配角的来历 | 卷四 |
| L5 | 终局真相 | 卷五 |

**硬规则**：写入表格后，任何一章都不得提前揭示更靠后的层级；需要铺垫时只给「错解」，不给「正解」。

## 操作手法

- **用「遗物解读」场景做说明书**：每次进入废墟/档案馆/数据中心，拾荒＝拆书，一次交代三重信息（旧世界结构/信仰体系/资源来源）。避免单开「设定章」。
- **用配角提问代替旁白**：让不懂行的人问出读者的疑问；主角回答时顺带交代设定。
- **主角视角吐槽当「翻译器」**：黑话＋比喻双轨——懂行的会心一笑，不懂的看比喻也懂。
- **留白制造信息差**：让教会/权威角色给出明显错误的解释，读者看得出是错的（戏剧反讽）。
